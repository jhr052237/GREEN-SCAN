# 그린스캔 GreenScan · 테스트 웹

화장품 바코드를 찍으면 비건 인증과 친환경 근거를 ESG 확인 점수로 보여주는 서비스의 체험판이에요.

- `index.html` 랜딩 페이지
- `app/` 눌러볼 수 있는 앱 체험판 (실물 조사 26개 제품, 점수 v2)
- `privacy.html` 개인정보 처리방침 (체험판 + 정식 서비스 초안)
- `data/products.json` 점수 계산 결과 (포장에서 확인한 근거만)

## 설문 연결
구글폼 '체험 연결용 링크'를 `app/app.js` 맨 위 `FORM_PREFILL`에 넣으면, 체험 마지막 화면의 설문 버튼에 체험 코드(A/B · 기준)가 자동으로 채워져요.

## 배포
Vercel에서 이 저장소를 Import 하면 정적 사이트로 바로 배포돼요. 빌드 설정은 필요 없어요.
